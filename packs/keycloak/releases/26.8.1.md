# Keycloak 26.8.1

The release that a new environment starts with. Published on 2026-10-13. The image is
`quay.io/keycloak/keycloak:26.8.1`, pinned by the digest of its index in the record
`26.8.1.json`. Quay builds a tag again when its base image changes, so the digest is the
artifact and the tag is the version.

- Security fixes: 22 issues, among them broken access control in the Admin REST API and in
  fine-grained admin permissions, a 2FA setup bypass, unsigned OIDC backchannel logout
  tokens and a path traversal through an X.509 CRL distribution point.
- The upgrading guide asks for action in one case: when email fails after the upgrade,
  check that the SMTP server supports STARTTLS, or turn off "Enable StartTLS".

Keycloak migrates its database when a new release starts, and it cannot roll the database
back. The record says `schema_change: true`: when the check after an upgrade fails, the
control plane does not go back to the old release. The way back is the database backup
from before the upgrade.

Sources: https://github.com/keycloak/keycloak/releases/tag/26.8.1 and
https://www.keycloak.org/docs/latest/upgrading/index.html
