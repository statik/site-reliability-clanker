# JupyterHub 5.5.5

The chart is Zero to JupyterHub 4.4.5 (2026-11-06), vendored as
`charts/jupyterhub-4.4.5.tgz` and pinned by its SHA-256 in the record `5.5.5.json`. The
chart runs the hub image `quay.io/jupyterhub/k8s-hub:4.4.5` (JupyterHub 5.5.5),
configurable-http-proxy 5.4.0, and the user image
`quay.io/jupyterhub/k8s-singleuser-sample:4.4.5`.

The upgrade from 5.5.4 restarts the hub and the proxy. Running user servers keep their
image until they stop; a server that starts after the upgrade gets the new user image.
The schema of the hub database is the same in each 5.x release (Alembic revision
`4621fec11365`), so the record says `schema_change: false`.
