# JupyterHub 5.5.4

The release that a new environment starts with. The chart is Zero to JupyterHub 4.4.4
(2026-10-20), vendored as `charts/jupyterhub-4.4.4.tgz` and pinned by its SHA-256 in the
record `5.5.4.json`. The chart runs the hub image `quay.io/jupyterhub/k8s-hub:4.4.4`
(JupyterHub 5.5.4, KubeSpawner 7.1.0), configurable-http-proxy 5.2.0, and the user image
`quay.io/jupyterhub/k8s-singleuser-sample:4.4.4`.

The schema of the hub database is the same in each 5.x release (Alembic revision
`4621fec11365`), so the record says `schema_change: false`.
