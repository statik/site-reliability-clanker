# Paperboat 1.1.1

Image tag: `1.1.1`. Schema version: 2 (no change).

## Summary

Security patch: a newer base image that fixes CVE-2026-00000 in the Debian 12 base. No
functional change.

## Changes

- Base image changes from `gcr.io/distroless/static-debian12:nonroot` to
  `gcr.io/distroless/static-debian13:nonroot`. Both are pinned by digest in `build.sh`.

  | Release | Base image digest |
  |---|---|
  | 1.1.0 | `sha256:afa5c872c891853ca7fcf1f12c3edb23f7eeef36189728842dd51042ff57f7ab` |
  | 1.1.1 | `sha256:aafe993665bf6200db38a02c11a9351e782a84b6a45e7f33b6695638c88e3931` |

- Fixes CVE-2026-00000: a flaw in a system package of the Debian 12 base image. The Debian 13
  base image has the fixed package. Paperboat does not call the package, so there is no
  known exploit path through the application. The patch removes the finding from image
  scans.
- `base_image` in `GET /api/version` and the footer of the UI show the new image. Use them
  to confirm that the patch runs.
- The Paperboat binary is built from the same source as 1.1.0. Only the version and base
  image values differ.

> CVE-2026-00000 is a placeholder identifier for the security-patch scenario of this
> prototype. It is not a published advisory. The base image change and the digests are real.

## Migration

None. The `pre-upgrade` hook runs and applies nothing. The schema stays at version 2.

## Risk

Low. No application code and no schema change.

- The rolling update replaces each pod. Open inventory streams reconnect on their own.
- Fault injection set with `/api/admin/fault` is in memory, so the restart clears it.
- Rollback to 1.1.0 needs no schema change, but it brings the vulnerable base image back.
