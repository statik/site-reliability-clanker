# Paperboat 1.2.0

Image tag: `1.2.0-bad`. Schema version: 2 (no change).

## Summary

Faster inventory board: the inventory list is now built from a snapshot for each tank.

## Changes

- `GET /api/inventory` builds its answer from a snapshot for each tank and no longer joins
  fish, species and tanks row by row. The answer has the same fields in the same order.
- The inventory board and the rental form load from the new code path. No change to the
  pages.
- No change to rentals, deliveries, support, the worker jobs or the inventory stream.
- Base image is the same as 1.1.1.

## Migration

None. The `pre-upgrade` hook runs and applies nothing. The schema stays at version 2.

## Risk

Low to medium. The change is in one read path, but it is the path with the most traffic.

- All inventory reads go through the new code: the board, the rental form and the synthetic
  customers.
- The health check `/api/healthz` does not call the inventory code. A problem in the new
  path does not show in readiness or liveness. Watch the error rate of `GET /api/inventory`
  and `errors` in `/api/stats` during and after the rollout.
- Rollback to 1.1.1 needs no schema change.
