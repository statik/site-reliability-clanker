# Paperboat 1.0.0

Image tag: `1.0.0`. Schema version: 1.

## Summary

First release: inventory, rentals, deliveries and customer support for the fish rental business.

## Changes

- Live inventory board, grouped by tank. The board updates from the inventory stream when a
  fish changes status.
- Rentals. A new rental reserves the fish and schedules a delivery. A return schedules a
  collection.
- Deliveries and collections. The worker moves each job from `scheduled` to `out` to `done`
  and writes a manifest to the shared volume when the van leaves.
- Support desk with tickets and interactions. The worker raises the priority of a ticket that
  stays open.
- Health certificates. The worker writes one file for each fish every 60 seconds.
- The age of each fish is shown. Nothing acts on it in this release.
- `POST /api/admin/fault` for incident exercises. It is off unless `ADMIN_TOKEN` is set.

## Migration

- Migration 1 creates all tables, the `schema_migrations` table and the trigger that feeds
  the inventory stream.
- On an empty database, the migration adds the starting stock: 8 species, 6 tanks, 60 fish
  and 20 customers.
- The migration runs as a Helm `pre-install` hook. It is safe to run again; it does nothing
  when the schema is current.

## Risk

Low. This is a new installation, so there is no data to change.

- The release needs a Postgres database and a `ReadWriteMany` volume at `/data`. The pods do
  not become ready until the database answers.
- Base image: `gcr.io/distroless/static-debian12:nonroot`, pinned by digest.
- Rollback: uninstall the release. Drop the database if you want to remove the data.
